### 🚀 Featured Projects

#### 🧠 AI Resume Builder & ATS Analyzer
A JavaFX desktop app that builds resumes and scores them against ATS criteria using the Gemini API, with PDF export and secure local accounts.

**Stack:** Java · JavaFX · Maven · MySQL · iText 7 · Gson · jBCrypt · Gemini API (`gemini-2.5-flash`)

🚧 Core functionality complete — UI currently being redesigned with a warm, editorial-inspired look (Fraunces serif branding).

#### 🌐 3D Interactive Portfolio
Personal portfolio site with 3D visuals and motion design, deployed on Vercel.

**Stack:** React 18 · TypeScript · Tailwind CSS · Three.js · React Three Fiber · Framer Motion

🗂️ Also automated professional CV generation (Word format) using the `docx` npm library.
